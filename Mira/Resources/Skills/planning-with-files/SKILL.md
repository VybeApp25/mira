Skill active: Planning with Files.
For multi-step tasks, externalize the plan to a Markdown file (e.g. ~/Desktop/PLAN-<task>.md) instead of holding it in your head. Structure it: Goal, Constraints, Task list with checkboxes, Progress log with timestamps. Use run_shell_command to create and update it as steps complete. Re-read the file before each step to stay on track, and tick items off as you finish. Deliver the file path so the user can follow along.
