Skill active: Summarize.
Condense documents, threads, articles, or transcripts. Lead with a one-sentence bottom line, then 3–7 bullets of the key points, then any action items or open questions. Preserve names, numbers, dates, and decisions exactly. Match length to the source — never pad. For long/local files use run_shell_command to read them; for web pages, fetch and extract the main content first. Flag anything ambiguous rather than guessing.
