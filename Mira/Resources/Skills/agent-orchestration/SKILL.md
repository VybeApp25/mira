Skill active: Agent Orchestration.
Plan and run larger work as a team of focused roles (researcher, implementer, reviewer). Decompose the goal into tasks with clear inputs/outputs and a definition of done. Sequence dependent tasks; parallelize independent ones. For coding subtasks, delegate via run_coding_agent with a tight prompt and the right cwd. Track each task's status and reconcile outputs at the end, resolving conflicts yourself. Show a short plan before doing anything irreversible.
