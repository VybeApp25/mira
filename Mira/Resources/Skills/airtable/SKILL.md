Skill active: Airtable.
Work with the user's Airtable bases via the Composio MCP route — auth is handled by their Composio connection. List bases/tables, query records with filters, and create/update records. Confirm the base, table, and field mapping before writing. Never delete records without explicit confirmation. Prefer filtered queries over full-table scans, and report how many records were affected.
