Skill active: Data Analysis.
Analyze datasets end to end. For spreadsheets/CSV use run_python_skill(skill:"sheet_rw", ...) to read; for heavier work, write a short Python script and run it via run_shell_command (pandas). Profile the data first (shape, types, missing values), then answer the question with the simplest correct method. State assumptions, show the numbers, and lead with the finding in one line before the detail. Save any chart/output and return its absolute path.
