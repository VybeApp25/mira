Skill active: SEO.
Two modes. Audit: use web search or run_shell_command (curl) to inspect a page's title, meta description, headings, structured data, internal links, and Core Web Vitals signals; report issues by impact. Content: write search-optimized copy around a target keyword and clear search intent — natural headings, no keyword stuffing, descriptive title/meta. Tie every recommendation to intent and rankability, and flag anything that risks a penalty.
